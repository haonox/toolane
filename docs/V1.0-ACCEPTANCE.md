## 检查命令与结果

本地普通测试、并发检查与静态检查均通过：

```bash
GOCACHE=/tmp/toolane-v10-go-cache GOPROXY=off go test ./...
GOCACHE=/tmp/toolane-v10-go-cache GOPROXY=off go test -race ./...
GOCACHE=/tmp/toolane-v10-go-cache GOPROXY=off go vet ./...
GOCACHE=/tmp/toolane-v10-go-cache GOPROXY=off go vet -tags=integration ./cmd/toolane ./tests/integration
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s examples -p 'test_*.py' -v
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s benchmarks -p 'test_*.py' -v
```

维护者使用 Docker 权限并复用普通用户的 Go 模块缓存，在当前验收分支运行：

```bash
sudo env PATH="$PATH" GOCACHE=/tmp/toolane-v10-go-cache \
  GOMODCACHE="$(go env GOMODCACHE)" GOPROXY=off \
  go test -tags=integration ./cmd/toolane ./tests/integration/... -count=1 -v
sudo docker container ls --all --filter label=toolane.project=toolane \
  --format '{{.ID}} {{.Names}} {{.Status}}'
```

服务包 6 项测试通过（包括新增真实进程崩溃测试），耗时 3.933 秒；集成包 7 项真实容器测试通过，耗时 8.713 秒。后续 Toolane 项目标签容器列表为空。集成包覆盖隔离、非零退出、输出洪泛、运行中超时、OOM、跨实例回收和资源归属持久化；Docker HTTP 服务包另覆盖启动回收、租户隔离、SSE 与执行。

## 结果边界

- Docker daemon 不可达、停止确认失败和删除重试使用可控后端故障测试验证；本轮没有主动中断宿主 Docker 服务。
- [负载实验](./V1.0-HTTP-EXPERIMENT.md)使用 Mock Executor 测量 HTTP/SQLite 路径。真实 Docker 验收使用有限个容器验证功能与恢复，没有测量容器吞吐或高并发性能；两者不能互相替代。
- 这些证据满足 [需求书](../REQUIREMENTS.md)中 V1.0 的本地 API 闭环、崩溃恢复及故障与负载实验退出条件。项目仍是单机版本；不宣称具备多实例共享数据库、自动重试、完整 SDK 或生产级敌对多租户隔离。
