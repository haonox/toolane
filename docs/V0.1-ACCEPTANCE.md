# V0.1 自动化验收记录

日期：2026-10-14。验收对象：单机内存执行闭环（Mock、可信 Linux Process、FIFO Worker、状态、取消、超时和输出限制）。该记录随 `feature/v01-acceptance` 分支提交，合并与阶段确认由维护者审查决定。

## 方法与环境

- 开发环境：Linux amd64，Go 1.27.1。Process 集成测试依赖 Linux 进程组与 `/proc`；其他平台的 Process 后端返回 `process_unsupported`。
- 并发测试用 channel 控制执行器的启动与返回顺序；短期限只用于触发真实超时，轮询和定时器有失败截止时间。
- 有界负载检查使用 2000 次满队列拒绝、20 次进程启动失败和 8 次真实进程取消或停机。内存检查在两次 GC 后比较堆占用，并给运行时噪声留 4 MiB 容差；Goroutine 趋势允许 8 个的测试环境波动。这是有限负载验收，不是长期稳定性或吞吐量声明。
- 执行器和进程测试检查终态、停止原因、队列与运行槽位；真实进程测试还观察进程是否停止。Linux 进程状态为 zombie 时表示它已停止运行；测试不验证宿主收养进程的回收时延。

准入还会在复制参数前检查大小，限制 Agent ID 与终态错误摘要的保留长度。对应测试为 `TestV01OversizedAdmissionDoesNotCopy`、`TestV01ErrorMessageIsBounded` 和 `TestV01ReturnedOutputIsBounded`。

本次一次独立运行的观测：ACC-01 峰值执行器数为 2/2；ACC-02 拒绝 2000 次后，GC 后堆占用从 282848 字节变为 204344 字节，Goroutine 数保持 5；ACC-07 的 8 次取消/停机后，Goroutine 数保持 2。这些数值随运行环境变化，判断依据是测试中的上限与终态断言。

## 复现命令

在仓库根目录运行：

```bash
go test -count=1 ./...
go test -race ./...
go test -race -count=10 ./internal/execution
go test -race -count=5 ./internal/executor/process
go vet ./...
go run ./cmd/toolane
go run ./cmd/toolane process
```

本次受限工作环境将 `GOCACHE` 指向 `/tmp/toolane-go-cache` 后运行上述命令；普通可写环境可直接使用。所有列出的检查在本分支通过。

## 仍然存在的边界

- Process Executor 仅运行服务端注册的可信程序。主动脱离进程组的后代、无法被内核及时停止的进程以及敌对代码不在 V0.1 的保证内。
- 记录只在内存中；退出服务后无法查询。HTTP、DAG、Docker 与持久化属于后续阶段。
- 有限次数的 race 与资源趋势检查不能证明不存在所有时序问题或长期泄漏；如需部署或提高负载，应另做长时实验并保存原始测量数据。
