# V1.0 Python 调用示例

[`examples/python_client.py`](../examples/python_client.py) 是只依赖 Python 标准库的本地 HTTP 调用示例。先按[本地 HTTP API](./V1.0-HTTP-API.md)启动 `toolane serve`，并确保 Token 的工具列表包含 `mock.delay`。在另一个终端运行：

```bash
export TOOLANE_TOKEN='填写服务配置中的私密 Token'
python3 examples/python_client.py run --delay-ms 100 --value 'hello from Python'
```

示例提交一次任务，立即打印 `execution_id`，随后定期查询至终态并打印完整 JSON 快照。还可使用以下命令查询或请求取消已接受的任务：

```bash
python3 examples/python_client.py get <execution_id>
python3 examples/python_client.py cancel <execution_id>
```

默认服务地址为 `http://127.0.0.1:8080`；如使用其他本地端口，可在子命令前传入 `--base-url http://127.0.0.1:端口`。示例只向显式的回环地址发送 Token，禁用环境代理和 HTTP 重定向。Token 从环境变量读取，不放在命令行参数或 URL 中。

如需在不确定提交响应是否到达时主动重试，可为同一请求复用 `--idempotency-key`。同键但参数不同会收到 `409/idempotency_conflict`。示例不会自动重试、不会在本地等待超时或按 Ctrl+C 时自动取消已接受任务；此时记下已打印的 ID，按需使用 `get` 或 `cancel`。退出码 `0` 表示任务成功，`1` 表示任务以其他终态结束，`2` 表示参数、HTTP、连接或本地等待失败。

此示例演示单任务的提交、查询和取消，属于调用示例，不是完整 Python SDK。Workflow 和 SSE 的接口契约见 [HTTP API](./V1.0-HTTP-API.md)与 [SSE](./V1.0-SSE.md)。

验证命令：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s examples -p 'test_*.py' -v
go test ./...
```

此外，已在临时本地 Toolane 服务上运行示例，验证提交、幂等重放与冲突、查询、认证失败、等待超时和取消。该端到端检查仅使用 Mock 工具，不需要 Docker。
