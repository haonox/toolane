# V1.0 本地 HTTP API 第一批

本批增加本地、持久化、Mock 工具的服务入口。`toolane serve` 在开放监听前打开 SQLite、执行恢复回调并构造 `NewDurableManager`。SIGINT/SIGTERM 时先停止 HTTP 接入，再关闭 Manager 和 Store。当前服务只注册 `mock.delay`；Docker 后端必须有完整的归属扫描与资源恢复装配后才能开放 HTTP 准入。若状态库留有待恢复的 Docker 资源，本地服务启动会失败。

## 启动

将以下 JSON 保存到自己选择的绝对路径，例如 `/home/you/toolane-server.json`，把 Token 改成随机生成的私密值。配置文件必须是普通文件，且只有文件所有者有访问权限；状态目录使用绝对路径。

```json
{
  "listen": "127.0.0.1:8080",
  "state_dir": "/home/you/toolane-state",
  "tokens": [
    {"token": "replace-with-a-private-random-token", "tenant_id": "local", "tools": ["mock.delay"]}
  ]
}
```

```bash
chmod 600 /home/you/toolane-server.json
go run ./cmd/toolane serve --config /home/you/toolane-server.json
```

服务只允许监听 `localhost` 或回环 IP，默认地址为 `127.0.0.1:8080`。配置文件中的 Token 映射到租户与明确的工具列表；请求体中的 `tenant_id` 会被拒绝。Token 不放在 URL，也不写入响应或日志。本地地址以外的部署须由明确配置的入口提供 TLS。

## 已实现的接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/v1/executions` | 提交单任务，可携带 `Idempotency-Key` |
| `GET` | `/api/v1/executions/{id}` | 查询本租户任务 |
| `POST` | `/api/v1/executions/{id}/cancel` | 取消本租户任务 |
| `POST` | `/api/v1/workflows` | 提交静态 DAG，可携带 `Idempotency-Key` |
| `GET` | `/api/v1/workflows/{id}` | 查询本租户工作流 |
| `POST` | `/api/v1/workflows/{id}/cancel` | 取消本租户工作流 |
| `GET` | `/healthz`、`/readyz` | 存活与就绪检查 |

业务接口使用 `Authorization: Bearer <token>`。提交请求最多 256 KiB，拒绝未知 JSON 字段与多余 JSON 值。单任务接受响应为 `202`，包含任务快照与实际采用的期限和字节上限。运行中取消返回 `202`，尚未运行或已终结时返回 `200`。跨租户查询和取消统一返回 `404`；工具不在该 Token 的允许列表中返回 `403`。错误体包含 `code`、`message` 和 `request_id`。

```bash
curl -sS -H 'Authorization: Bearer replace-with-a-private-random-token' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: demo-1' \
  -d '{"agent_id":"demo","tool":"mock.delay","arguments":{"delay_ms":100,"value":"hello"}}' \
  http://127.0.0.1:8080/api/v1/executions
```

本批不含 `/api/v1/executions/{id}/events` SSE；事件回放、实时推送、管理指标及 Docker 服务装配仍在后续批次。当前端点的隔离测试覆盖两个 Token 映射的租户、任务与 Workflow 的跨租户查询和取消，以及幂等重放、冲突、无效请求和大小上限。
